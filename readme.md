# MapSpy 🗺️🚓

MapSpy is a **purely experimental and hobbyist** map/navigation interface project that visualizes publicly available data.

## 📌 About the Project

- **Developed by AI:** All source codes, algorithms, and interfaces of this project were generated by Google Gemini AI as part of a trial/learning process.
- **Open Source Data (OSINT):** All data included in the application (radars, electronic enforcement systems, speed corridors, facilities, etc.) is compiled from anonymous, open-source data publicly available on the internet.
- **No Manual Data Entry:** No data was added manually, leaked, or obtained from confidential/official sources. The system simply visualizes existing open data.
- **For Entertainment and Learning Purposes:** This project has no serious purpose, commercial goal, or official status. It is published entirely for learning how to code, testing map APIs, and creating an "entertaining" hobby project.

- The application consists of only a single `HTML` file.
- Simply open it in your browser to run it; it does not require a server.
- It uses Leaflet.js and open-source map providers.
